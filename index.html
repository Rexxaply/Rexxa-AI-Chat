1. Hubungkan ke Supabase

Database gratis tempat chat, profil AI, dan pengaturanmu disimpan. Cukup sekali di setiap perangkat, atau pakai link penyambung.

  1. Buat akun dan project baru di supabase.com.
  2. Buka SQL Editor, tempel kode di bawah, lalu klik Run.
  3. Buka Project Settings → API, salin Project URL dan kunci anon / publishable.
