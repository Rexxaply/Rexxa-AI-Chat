# Terjemahkan foto (edit gambar AI) — REXXA AI

## Cara pakai
1. Lampirkan foto (📎 → Foto/Kamera).
2. Tulis misalnya: *"terjemahkan foto ini ke bahasa Inggris"*.
3. REXXA mengirim foto ke model edit gambar OpenAI dan membalas dengan **PNG** yang teksnya sudah diganti.
4. Ketuk kartu hasilnya untuk **membandingkan sebelum/sesudah**, atau tekan **PNG** untuk mengunduh.

Kalau kamu hanya bertanya arti tulisannya, AI menjawab dengan teks biasa (tanpa biaya edit gambar).

## Pengaturan (Dashboard → Koneksi bawaan → Edit gambar AI)
- **API key OpenAI** — kosongkan bila koneksi bawaanmu sudah OpenAI (key bawaan dipakai otomatis).
- **Model** — `gpt-image-2.5-sunburst` (paling presisi, bawaan) atau `gpt-image-2.5-flare` (lebih cepat).
- **Kualitas** — Rendah/Sedang/Tinggi. Makin tinggi makin tajam teksnya dan makin mahal.
- **Konfirmasi** — REXXA bertanya dulu sebelum memproses gambar berbayar.
- **Cek akses model** — memastikan key-mu bisa memakai model itu (tes ini gratis).

## Catatan
- Biaya dihitung per gambar oleh OpenAI sesuai model & kualitas; cek halaman pricing OpenAI.
- Beberapa akun OpenAI perlu verifikasi organisasi sebelum bisa memakai model gambar.
- Model gambar kadang mengubah detail kecil atau salah eja (terutama huruf non-Latin). Periksa hasilnya sebelum dipakai resmi.
- Hasil PNG berukuran beberapa MB. Jika "Sinkronkan gambar" dimatikan, PNG hasil hanya tersimpan di perangkat pembuatnya.
